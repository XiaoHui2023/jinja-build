# 示范

各子目录为独立模板工程，演示 Jinja2 与 jinja-build 的常见用法。

| 目录 | 主题 |
| --- | --- |
| [jinja-basics](jinja-basics/README.md) | 变量、分支、循环、过滤器、include、空白控制 |
| [filters](filters/README.md) | property、内置过滤器、models 方法作过滤器 |
| [macros-advanced](macros-advanced/README.md) | macro、extends、import |
| [optional-output](optional-output/README.md) | 条件生成；空白结果不写文件 |
| [models-imports](models-imports/README.md) | models.py 引用同目录 Python 包 |
| [config-variables](config-variables/README.md) | 配置里的 `${}` 引用 |
| [multifile-config](multifile-config/README.md) | `#文件名` 捆绑与 `!include` |
| [third-party-rich](third-party-rich/README.md) | models.py 导入第三方库 rich |
