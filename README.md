# jinja-build

## 设计特性

### 模板目录

默认面向一整个模板目录工作。目录里可以放多份模板，输出时会保留相对层级，便于把一组相关文件一起生成。

也可以只给单个模板文件。这个模式适合临时生成一个文件，或在调试模板时缩小范围。

### 数据建模

模板旁边放一份数据结构定义，配置会先转成稳定的数据对象。模板看到的是整理后的数据，不需要自己处理原始配置里的细节。

数据结构里的公开方法也会放进模板可用范围。适合把常用计算收在数据对象附近，避免模板里写太多判断。

### 文档生成

文档生成器会在模板根目录里寻找带数据结构文件的仓库。每个仓库独立生成一份 Markdown，输出时保留仓库相对层级。

文档内容来自数据结构本身。字段名称、类型、必填状态、默认值和说明会整理成表，适合先看文档再决定怎么填配置。

### 配置格式

输入配置交给统一加载器读取。只要加载器支持，配置就不限于某一种文件格式。

空输入会按空配置处理。这样同一套模板可以先跑起来，再逐步补齐需要的数据。

### 空白输出

模板渲染后如果只剩空白内容，就不会写出文件。条件模板可以靠这个规则自然跳过，不需要额外维护文件清单。

这个规则按渲染结果判断。全是空格或换行也会被当作空内容。

### 批量渲染

批量模式复用同一套模板和数据结构。每个输入配置都会生成一个独立输出目录，目录名来自输入文件名。

批量输入之间不允许输出名重复。发现重名会在开始时直接报错，避免互相覆盖。

### 并行任务

渲染任务会按输入数量和有效模板数量展开。单次输入会并行渲染多个模板，批量输入会进一步把所有组合一起调度。

并行数量会按机器可用 CPU 和任务数量收敛。模板多、输入多时可以更好地利用本机资源。

### 导入隔离

模板侧的数据结构文件会在独立名字下加载。这样即使不同目录里有同名文件，也不容易互相串扰。

加载期间会临时允许同目录辅助文件被引用，结束后恢复环境。这样模板目录可以自带小工具，同时不长期影响主程序。

### 远程服务

服务端部署时固定一个模板根目录。外部请求只能在这个根目录下选相对模板路径，不能把任意模板路径塞进请求里。

请求会上传本次输入配置，响应直接返回生成文件。模板路径写错时会返回一个相近路径，方便调用方快速修正。

请求和渲染结果会写入服务端日志目录。模板渲染报错只影响本次请求，服务会继续处理后续请求。

## 配置

### `template`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-t`, `--template` | 模板目录或单个模板文件。目录模式会扫描其中的模板文件。 | 无 |

### `input`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-i`, `--input` | 单个输入配置文件。会输出到指定输出位置。 | 空配置 |

### `batch`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-b`, `--batch` | 多个输入配置文件。会共用同一套模板，每个输入生成一个独立目录。 | 无 |

### `output`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-o`, `--output` | 单次模式下是输出位置；批量模式下是输出根目录。 | 无 |

### `models_filename`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-mf`, `--models-filename` | 模板目录中的数据结构文件名。 | `models.py` |

### `server.port`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-p`, `--port` | 服务端监听端口。 | 无 |

### `server.template`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-t`, `--template` | 服务端允许使用的模板根目录。 | 无 |

### `server.log`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-l`, `--log` | 服务端写入的日志目录。 | 无 |

### `server.request`

| 键 | 说明 | 默认 |
| --- | --- | --- |
| `template` | 相对服务端模板根目录的模板路径。 | 无 |
| `input` | 上传的输入配置文件。 | 空配置 |
| `models_filename` | 数据结构文件名。 | `models.py` |

### `doc.template`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-t`, `--template` | 要监听的模板根目录。 | 无 |

### `doc.output`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-o`, `--output` | 文档输出根目录，会按仓库相对层级写出。 | 无 |

### `doc.log`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-l`, `--log` | 日志输出目录，文件会按年月日和时分秒分层写入。 | 无 |

### `doc.models_filename`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-mf`, `--models-filename` | 用于识别仓库的数据结构文件名。 | `models.py` |

### `doc.interval`

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-i`, `--interval` | 检查目录变化的间隔秒数。 | `1.0` |
